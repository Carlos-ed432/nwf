### 🎲 2. Jogo de Adivinhação

Jogo em Python no qual o computador sorteia um número de **1 a 10** e o usuário precisa descobrir qual foi escolhido.

O programa continua solicitando tentativas até que o número seja descoberto e também contabiliza a quantidade de tentativas.

**Prática:**

`random` • `while` • `if/elif/else` • acumuladores • `input()` • conversão de tipos • tratamento de erros

### 👥 3. Sistema de Cadastro de Pessoas

Sistema em Python com menu para visualizar, cadastrar e armazenar pessoas.

O projeto também trabalha com **manipulação de arquivos e persistência de dados**.

Uma das funções verifica automaticamente se o arquivo de cadastro existe e, caso não exista, cria o arquivo antes da execução do sistema.

Também pratiquei:

- Modularização
- Funções
- Validação de dados
- Tratamento de exceções
- Manipulação de arquivos `.txt`
- `pathlib`
- Organização de módulos
- Persistência de informações

**Objetivo:** transformar os conhecimentos de lógica em uma aplicação com uma estrutura mais próxima de um sistema real.
